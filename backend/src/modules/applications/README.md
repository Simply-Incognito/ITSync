# Applications module

Owns application submission, duplicate prevention, status transitions, and status history. Organization representatives can list applications page-by-page for an opportunity they own, view the applicant profile and submitted documents, and accept or reject applications. Review and document access is scoped to the representative's organization. A successful application creates an application record without changing the opportunity's posted slot count. Public opportunity results include an application count for student discovery. Keep an application linked to student and opportunity IDs, and make transition rules explicit in the application service.
